## Description

```text
tikz-tensor-networks is a LaTeX package for drawing tensor-network diagrams from a description of tensors, indices and connections. It supports matrix product states, tensor trains, PEPS sheets, string diagrams and channel diagrams through a common TikZ-based language.

The package provides the tenkz and tenkzeq environments and includes a PDF manual with rebuildable LaTeX sources. It requires LaTeX2e with expl3, pgf/TikZ, hobby and spath3.
```

## Announcement via mailing list and RSS

```text
This is the first CTAN release of tikz-tensor-networks, a LaTeX package for drawing tensor-network diagrams from a description of tensors, indices and connections.

Version 0.8.0 supports matrix product states, PEPS sheets, string diagrams and channel diagrams. Load it with \usepackage{tikz-tensor-networks}; diagrams use the tenkz and tenkzeq environments.

The package includes a PDF manual and its LaTeX sources and is distributed under the Apache License 2.0. This is a pre-1.0 release; the 1.0 compatibility freeze is not claimed.

Project: https://github.com/LionSR/tenkz
```

## Administrative notes
